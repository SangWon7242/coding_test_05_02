# 자바 코딩테스트 준비 가이드

## 1. 단계별 문제 해결 접근법

### 기초 다지기
- **쉬운 문제부터 시작하기**
    - 백준 Bronze, Silver 레벨 문제부터 시작
    - Programmers Level 1 문제로 기초 다지기
    - 기본 입출력, 조건문, 반복문 문제 위주로 연습

### 문제 풀이 기록 관리
- **GitHub를 활용한 기록 관리**
```markdown
- 문제 제목과 난이도
- 문제 해결 아이디어
- 사용한 알고리즘/자료구조
- 시간복잡도 분석
- 개선할 점
```

- **다른 사람의 풀이 학습**
- 같은 문제의 다양한 해결 방법 비교
- 코드 최적화 방법 학습
- 새로운 접근 방식 발견

## 2. 문제 해결이 어려울 때

### 체계적인 학습 방법
1. **문제 분석 단계**
- 문제를 작은 단위로 분해
- 입력과 출력 관계 파악
- 제약 조건 정리

2. **해결 방법 탐색**
- 구글 검색을 통한 유사 문제 찾기
- 관련 알고리즘 학습
- ChatGPT 등 AI 도구 활용
  ```
  - 문제 해결 접근 방식 요청
  - 단계별 설명 요청
  - 다양한 해결 방법 비교
  ```

3. **다양한 풀이 방법 학습**
- 온라인 커뮤니티 활용 (백준, 프로그래머스 등)
- 유튜브 알고리즘 강의 시청
- 코딩테스트 관련 블로그 구독

## 3. 자료구조 학습 전략

### 핵심 자료구조 마스터하기
1. **기본 자료구조**
 ```java
 - Array, ArrayList
 - LinkedList
 - Stack, Queue
 - HashMap, HashSet
```

2. **고급 자료구조**
 ```java
- Tree (Binary Tree, BST)
- Heap (PriorityQueue)
- Graph
- Trie
```

### 실전 응용
- 자료구조별 대표 문제 풀이
    - 각 자료구조의 특징을 활용하는 문제 선별
    - 시간복잡도를 고려한 자료구조 선택
    - 실제 코딩테스트에서 자주 출제되는 유형 학습

### 추가 학습 팁
#### 시간 관리
- 하루 1-2문제 꾸준히 풀기
- 난이도별로 시간 제한 두고 풀기
- 주말을 활용한 복습 및 심화 학습

### 오답 노트 작성
```markdown
1. 문제가 어려웠던 이유
2. 핵심 알고리즘/자료구조
3. 실수했던 부분
4. 다음에 비슷한 문제를 만났을 때의 해결 전략
```

### 코드 리뷰 습관
- 시간복잡도 개선 가능성 검토
- 코드 가독성 향상
- 변수명과 주석 정리
- 예외 처리 보완
